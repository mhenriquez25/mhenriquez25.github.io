Conexión con Base de Datos Gratuita (Google Firebase)

¿Cómo funciona la sincronización en la nube gratuita?
Al conectar Google Firebase Firestore (100% gratis de por vida para proyectos pequeños):
  1. Cada producto que agregues o edites aquí se guarda en la nube al instante.
  2. Cualquier cliente que entre a tu web en cualquier parte del mundo verá tus productos actualizados en tiempo real.
  3. Pasos sencillos para obtener tus llaves gratuitas:
    • Entra a Firebase Console con tu cuenta de Google.
    • Crea un proyecto gratis (ejemplo: ModaCasual).
    • En el menú izquierdo ve a Firestore Database -> Crear base de datos (elige 'Modo de prueba').
    • En Configuración del proyecto -> 'Tus apps', añade una app Web y copia el objeto firebaseConfig.
